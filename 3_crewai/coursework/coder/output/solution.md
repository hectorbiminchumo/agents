I wrote a Python program in the sandbox as `leibniz_pi.py` to calculate the first 1,000,000 terms of the Leibniz series:

`1 - 1/3 + 1/5 - 1/7 + ...`

The program uses Python’s `decimal` module for high precision, sums the first 1,000,000 terms, multiplies the result by 4, and prints the approximation.

Final output from running the script:
`3.1415916535897932387126433832791903841971703525036`
